# receipt-logs-app

Админ-панель «Журнала прихода товара» (React 19 + TypeScript + Vite, TanStack Query, React Router).
Интерфейс на русском.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
```

В разработке запросы `/api` проксируются на бэкенд `http://localhost:4000`
(сначала запустите `receipt-logs-api`).

## Продакшен

Укажите адрес API в `.env` (см. `.env.example`):

```
VITE_API_URL=https://api.example.com
```

затем `npm run build` — готовые файлы в `dist/` (например, для Vercel).
На бэкенде добавьте адрес фронтенда в `CORS_ORIGIN`.

## Разделы

- **Магазины** — список; клик по магазину открывает его рабочее пространство:
  - **Журнал прихода** — месячная таблица как бумажный журнал (продукты × дни 1–31, «Итого»). Число вводится прямо в ячейку, Enter — сохранить и перейти ниже. Кнопка «Внести приход» — быстрый ввод с прибавлением к уже внесённому за день.
  - **Отчёты** — что пришло больше всего за сегодня / неделю / месяц / любой период, отдельно по кг и по шт, динамика по дням/неделям/месяцам, выгрузка CSV.
  - **Продукты магазина** — свой набор продуктов у каждого магазина; новый продукт можно создать прямо здесь.
- **Отчёты** — то же по всей сети или по выбранному магазину, плюс сравнение магазинов.
- **Продукты** и **Категории** — общий каталог.
